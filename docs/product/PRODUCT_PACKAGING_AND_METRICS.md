# 13 — Product Packaging and Commercial Metrics

## 1. Possible editions
These are packaging concepts, not pricing commitments.

| Edition | Illustrative scope |
|---|---|
| Community / Self-hosted | Core recorder, transcription, basic document export, standard TTS, documented limits |
| Professional | Team workspaces, higher quotas, templates, search, collaboration, advanced exports |
| Enterprise | SSO, advanced audit, retention/legal hold, private deployment, admin controls, integrations, support SLAs |
| Voice Studio add-on | Consent-managed voice profiles, synthesis quotas, governance, usage analytics |

## 2. Delivery models
- Hosted SaaS
- Private/on-premises licence
- Enterprise support
- Optional managed deployment

## 3. Cost model
Self-hosted AI can reduce variable external API charges but does not eliminate costs. Measure:
- compute cost per recording hour
- transcription hour
- generated audio minute
- storage GB-month
- network/bandwidth
- backup and recovery
- engineering and support effort
- customer acquisition and onboarding

## 4. Commercial decision gates
Do not set final prices until pilot usage and infrastructure benchmarks exist. Define fair-use quotas, concurrency, retention, storage, support, and private deployment boundaries for each edition.

## 5. Product metrics
- Active organisations and users
- Meetings recorded and processing completion
- Median time from upload to reviewed transcript
- Minutes preparation time saved
- Transcript correction rate
- TTS completion and repeat usage
- Search/assistant usefulness and citation validity
- Storage and compute cost per tenant
- Support incidents and resolution time
- Retention, renewal, and customer satisfaction
