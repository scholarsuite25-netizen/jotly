# Antigravity Prompt — Repository Review Only (No Code Changes)

Inspect the repository and the NEXUS Markdown specifications. Do not create, edit, delete, rename, install, migrate, or execute project files.

Report:
1. Existing app structure and technologies.
2. Implemented features with file evidence.
3. Missing requirements mapped to the documentation.
4. Security and tenant-isolation risks.
5. Model/licence and privacy questions.
6. Build/test status based only on commands actually run.
7. Recommended next vertical slice.
8. Exact files you would change in that next slice.

Clearly distinguish verified facts from assumptions. Do not claim a feature exists based only on a filename or UI placeholder.
